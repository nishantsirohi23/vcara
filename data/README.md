## Schema for checkpoint summaries (`checkpoints.csv`)

| Column | Meaning |
|---|---|
| `frames` | Environment frames at the checkpoint |
| `mean_return`, `std_return` | Mean and within-evaluation SD of episode return |
| `mean_coverage`, `median_coverage`, `p90_coverage` | Coverage distribution over evaluation episodes |
| `off_road_frac` | Fraction of frames with all four wheels off track |
| `mean_speed` | Mean hull speed over the episode |
| `t90` | Frames to reach coverage 0.90, or -1 if never reached |
| `seed`, `variant` | Required once multi-seed summaries are added |

Each row should be generated by `scripts/make_figures.py` from a run JSON log,
so every number can be traced to its source.
